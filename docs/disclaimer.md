## 目标平台服务规则与风控自担

各招聘平台（包括但不限于 BOSS 直聘、猎聘、前程无忧、智联招聘）的服务协议通常禁止未经许可的自动化采集。使用采集功能，可能触发平台的验证码拦截、访问频率限制、账号降权、功能受限乃至封号等处置措施。

本项目的采集在使用者本机进行：通过专用的 Chrome 浏览器，以使用者本人的账号，读取其本可正常访问的页面。遇到登录、验证或访问限制时，当前平台的采集即停止并交由使用者处理，本项目不自动重试，也不绕过任何验证。每个平台 24 小时内最多新增 200 个岗位，翻页与读取详情之间均设有间隔。上述措施旨在降低风险，但不能保证账号不受影响。

是否使用采集功能、采集多少，均由使用者自行决定，由此产生的一切后果与责任由使用者独立承担。平台改版或风控策略调整，亦可能导致采集功能暂时失效。

本项目不代替使用者投递简历，也不代替使用者向招聘方发送消息。沟通建议中生成的回复草稿，是否发送、如何发送，均由使用者决定。

## 本地存储与零回传承诺

本项目遵循本地优先（Local-First）原则，不设中心化服务器与账号体系，不收集、不回传、不转存使用者的任何数据。简历、岗位、沟通记录、成果文件、专用 Chrome 的登录状态及模型 API Key，均仅保存在本机迁跃目录下的 `data/` 目录中。

数据由使用者自行保管与备份。删除迁跃目录前，请先备份 `data/` 目录；数据丢失或损坏的，作者无法协助恢复。

## 第三方模型、Agent 与搜索服务

本项目自身不上传数据，但 AI 功能依赖使用者自行选择的外部服务：

- 配置了模型 API Key 时，发起 AI 任务会把该任务所需的简历、JD、对话或截图发送至使用者配置的模型服务。
- 通过 MCP 把任务交给使用者自己的 AI Agent（如 Claude Code、Codex、Cursor）时，任务所需的内容由该 Agent 读取，并发送至该 Agent 所使用的模型服务。
- 进行公司研究与面经检索时，检索词将发送至使用者选择的搜索服务。

「发送给模型前隐藏个人信息」功能默认开启，会将常见的手机号、邮箱及使用者指定的词语替换为占位符。该功能基于规则匹配，不能保证识别全部个人信息。截图无法自动打码，会以原图发送，请在发送前自行遮挡个人信息。

上述服务依据其各自的服务条款与隐私政策处理数据，相关费用由使用者与服务商直接结算。
